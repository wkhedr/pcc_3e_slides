# Python Crash Course Slides

This repository contains illustrated companion lecture-slide resources created for the Chinese edition of Eric Matthes' *Python Crash Course, 3rd Edition*. The materials are designed to be used alongside the book.

Online preview. Downloading the PPT files is recommended because the web preview may load slowly and does not preserve the full animation effects:

https://scruel.github.io/pcc_3e_slides

## About the Content

This repository can be viewed as the author's notes on the book, published in lecture-slide format and based on the author's own reading and understanding.

The slides can be useful not only for teaching, but also for self-study. Studying them alongside the book may help readers understand the material more effectively:

- The slides follow the book's content and explanation order, with animations arranged to support use alongside the original book.
- The author drew dozens of explanatory diagrams, mainly using [Excalidraw][excalidraw], as visual aids for key concepts.
- The slides include "Expand a Bit" sections, which point out basic supplementary topics worth learning and preview some more advanced ideas.
- Some code and explanations from the book have been adapted so that they fit the limited slide space and work better for teaching.
- Some subsections were slightly reordered to make use of slide-by-slide comparison and presentation flow.

The author hopes these materials help readers of the book. **Happy Pythoning!**

## Notes from the Author

After finishing the book, the author felt that it is an excellent introduction to programming. It is readable even for complete beginners, covers the fundamentals broadly, and provides practical small goals that let readers apply what they learn immediately in the project chapters. While explaining concepts step by step, the book repeatedly emphasizes writing clean and efficient code, helping readers build good coding habits. Many books do not spend much effort on this point, which makes it especially valuable.

Although the slides have been checked many times, mistakes and imperfections are inevitable because of limited time and energy. The design style is also relatively simple. If you find errors or have constructive suggestions, please open an issue.

### Notes or Lecture Slides?

For learners with little or no experience, it can be difficult to identify the key points when taking notes, and they may sometimes write down incorrect explanations. More experienced learners may omit details that are important for understanding because their notes are usually written for themselves. In either case, notes often contain large copied sections. Unless the notes are written for a broad audience, their reading experience may not be better than the original book.

Lecture slides are different. A slide has limited space, but it still needs to carry enough conceptual content. Text-heavy slides can easily become little more than a direct reading of the textbook. This limitation led the author to think carefully about the format. Since these slides are intended to accompany the book, they need to remain closely aligned with it and cover as much of the original content as possible. However, simply moving text onto slides would be dull. For that reason, the author decided to make this an illustrated set of lecture slides, which required more time and effort.

### Why Illustrated?

There are already many books and notes marketed as "illustrated" introductions to various subjects, but the author feels that many of them are not very helpful:

- Some illustrations do little to support understanding and feel like filler; plain text would sometimes be better.
- Even when an illustration is meant to help, it may lack a vivid and accurate analogy, or the analogy may be misleading.

For these slides, the author mainly adds diagrams at key conceptual points and uses presentation features to make the diagrams "move." This should help with understanding and learning. Although the author's drawing ability is limited and some better analogies may not have been used, the released diagrams are intended to match the concepts as closely as possible.

## English Translation Work

This fork is prepared for an English translation/adaptation of the slide resources. The original Chinese PPT files are kept in `PPT/`. English translated decks should be placed in `PPT_EN/` so that the original files remain untouched.

Recommended translation policy:

- Preserve slide order, layout, diagrams, code blocks, and animations as far as possible.
- Keep Python keywords, identifiers, filenames, shell commands, and code comments unchanged unless the comment itself is explanatory Chinese text.
- Use natural English teaching language rather than literal word-for-word translation.
- Preserve attribution to the original author and the CC BY-NC-SA 4.0 license.
